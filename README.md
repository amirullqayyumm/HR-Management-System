
# HR Management System (HRMS)

A full-stack Human Resource Management System designed to simplify employee management, attendance tracking, leave applications, and organizational reporting.

## Tech Stack

**Frontend:** React, Vite, JavaScript, CSS

**Backend:** Node.js, Express.js

**Database:** PostgreSQL

**ORM:** Prisma

**Authentication:** Session-based authentication and role-based access control

## Key Features

- Secure user login and logout
- Role-based access for HR Admin, Manager, and Employee
- Employee registration and profile management
- Department and position management
- Employee activation and deactivation
- Interactive organizational hierarchy
- Leave applications and manager approvals
- Leave balance management
- Employee attendance tracking
- HR attendance reporting
- Personalized dashboards
- Light Mode and Dark Mode

## User Roles

| Role | Main Responsibilities |
|------|-----------------------|
| HR Admin | Manage employees, departments, positions, and HR records |
| Manager | View team information and manage leave approvals |
| Employee | View personal information, attendance, and leave records |

## Project Structure

- `frontend/` - React user interface
- `backend/` - Express API, Prisma, and database logic
